# 🏧 C++ ATM System

A simple console-based ATM System developed using C++.

## 📌 Description

This project simulates the basic functionality of an ATM machine using C++.

The program allows users to check their account balance, deposit money, withdraw money, and exit the application through a menu-driven interface.

This project was built to practice functions, loops, switch statements, and conditional logic.

---

## ✨ Features

- 💰 Check account balance
- ➕ Deposit money
- ➖ Withdraw money
- 📋 Menu-driven interface
- 🔄 Repeats until the user chooses to exit

## 🚀 How to Run

### Compile

```bash
g++ main.cpp -o atm
```

### Run

```bash
./atm
```

(Windows users can run `atm.exe`.)
